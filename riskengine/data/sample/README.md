# Sample data (SYNTHETIC)
`news_sample.jsonl` and `tweets_sample.jsonl` are hand-written scenario text used as the offline demo fallback.
They are NOT real news or tweets and carry no ground-truth labels. Every record loads with `simulated=true`.
Real datasets: put Kaggle files in `data/raw/` as `all-data.csv` (financial news) and `tweets.csv` (tweets).
